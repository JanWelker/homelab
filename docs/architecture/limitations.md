# Known Limitations

Things this cluster does not do. None is a bug; each is an accepted tradeoff
or work not yet done.

| Limitation | Consequence | Mitigation / plan | Where documented |
| --- | --- | --- | --- |
| **The API endpoint address is fixed at `kubeadm init`** | The kube-vip VIP is baked into the API server certificates, every kubeconfig and Cilium's `k8sServiceHost`; moving it touches every node | Choose it once, outside any DHCP range and the LoadBalancer pools; the next build [uses a name](../operations/control-plane-vip.md#endpoint-name) | [Choosing the address](../operations/control-plane-vip.md#choosing-the-address) |
| **OpenBao needs an operator to unseal it** | Every restart seals it until the [threshold of key shares](../platform/openbao.md#at-a-glance) is supplied; sealed, no `ExternalSecret` resolves and certificates silently stop renewing | Check `bao status` after reboots; auto-unseal would add an external dependency | [Unsealing after a restart](../platform/openbao.md#unsealing-after-a-restart), [after any node reboot](../operations/nodes.md#after-any-node-reboot-unseal-openbao) |
| **One operator holds every credential** | The unseal key shares and `output/credentials/` sit with one person, on the deployment host | Copy them to a password manager | [Bootstrap](../platform/openbao.md#bootstrap), [Repository layout](index.md#repository-layout) |
| **Alerting reaches one mailbox** | A rejected mail, an expired SMTP password or a Ceph outage ([Prometheus and Alertmanager](../platform/monitoring.md#at-a-glance) sit on Ceph) stops alerts silently; `Watchdog` proves only as far as Alertmanager | An off-cluster `Watchdog` mail check; meanwhile, the routine health check | [Alerting](../platform/monitoring.md#alerting), [routine health check](../operations/index.md#routine-health-check) |
| **Automatic updates stop at patch releases** | Nodes follow the Kubernetes minor they were built with; a minor upgrade is manual | By design | [Nodes are pinned to a minor series](../operations/upgrades.md#nodes-are-pinned-to-a-minor-series), [upgrading a minor deliberately](../operations/upgrades.md#upgrading-a-minor-version-deliberately), [Kured](../platform/kured.md) |
| **The `infra` AppProject is permissive** | The `infra` AppProject allows every kind in every namespace, so a platform `application.yaml` can deploy anything anywhere | Narrow the projects | [Security Posture](security.md#authorization) |
| **Reprovisioning needs the boot server on the segment** | Rebuilding a node needs `make serve` on the nodes' L2 segment, the DHCP pointing at it and a power cycle; there is no remote rebuild | A running node reboots and rejoins without it | [Boot & Bootstrap Process](boot-process.md#every-boot-after-the-first) |
| **The object store survives one host down, no more** | During every Kured reboot the RGW data pool, which holds the backups and Loki chunks, has no redundancy left, while `rbd-pool` still has some | Accepted: a pool's erasure profile is fixed, so fixing it means a new pool and moving every bucket | [Object storage](../platform/rook-ceph.md#object-storage) |
| **Cluster admin is a client certificate, not OIDC** | `output/kubeconfig` is `admin.conf`, a certificate only a CA rotation revokes; the API server has no OIDC | Accepted: one operator, LAN-only API | [Authorization](security.md#authorization) |
| **OpenBao speaks plain HTTP inside the cluster** | Secrets and tokens cross the pod network unencrypted; WireGuard covers node-to-node | Accepted: a certificate would sit in the unseal path | [OpenBao](../platform/openbao.md#at-a-glance) |
| **OSDs are unencrypted, the Rook toolbox is on, Loki has no tenants** | A pulled disk is readable; the toolbox is a standing Ceph admin shell; any Grafana Viewer reads every log line, the audit log included | Accepted: disks stay on site, runbooks need the toolbox, one Grafana user | [Rook-Ceph](../platform/rook-ceph.md), [Logging](../platform/logging.md) |
| **SELinux is permissive on every node** | Flatcar's default: SELinux does not mediate a container escape, and Tetragon detects without confining | The denials are answered; enforce on one worker first | [Node hardening](security.md#node-hardening) |
| **Ceph's daemons run privileged** | `hostpathRequiresPrivileged`, Rook's switch for SELinux hosts: `container_t` may not write their hostPath data. A privileged container has every capability and no seccomp filter | Accepted until the paths carry a label | [Rook Ceph](../platform/rook-ceph.md#selinux) |
| **The `infra` hostnames and the LAN address are in public DNS** | The infra names resolve publicly to a LAN address, so anyone can list them; they stay LAN-only | Accepted: no split DNS to run | [external-dns](../platform/external-dns.md) |
| **Single region, site and rack** | Ceph replicates across nodes on one power feed and TrueNAS pulls the backups over the same LAN ([Off-cluster copy](../operations/backups.md#off-cluster-copy)), so a site-level event takes everything | Honest limit of a homelab: a copy off the site | — |
| **No staging cluster** | A merge to `main` is a production deployment | The pull request checks and diff preview | [Contributing](../development/contributing.md) |
| **The router and Authentik stand alone** | The router carries every Internet request and the BGP sessions; Authentik every UI login | LAN clients still reach the Gateways over L2 | [Cilium](../platform/cilium.md#configuration), [When Authentik is down](../platform/authentik.md#when-authentik-is-down) |
| **Backup copies hold plaintext Secrets and one all-powerful key** | Velero's resource backups keep Secrets as plain JSON, and the NAS's `offsite-reader` key owns the bucket, so a leak of either exposes every Secret or the backups themselves | Accepted; the NAS's snapshots outlive a deletion | [Repository password](../platform/velero.md#repository-password), [Off-cluster reader](../platform/rook-ceph.md#off-cluster-reader) |
